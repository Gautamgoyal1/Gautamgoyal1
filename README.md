An AI-powered interview preparation system designed to help candidates prepare for technical interviews.

- **Resume analysis:** Identify skill gaps and generate role-relevant interview preparation recommendations.
- **Interview simulation:** Support structured interview sessions with follow-up questions and feedback.
- **Knowledge-grounded evaluation:** Use retrieval and structured workflows to support more consistent assessments.

**Tech:** Python · FastAPI · LangChain · LangGraph · RAG · PostgreSQL/pgvector · Docker

A multi-stage AI agent project designed to turn topic-based news discovery into a relevant, summarized digest.
